# 尺规作图 · 六项功能升级实施计划

## Context

todo.txt 提出 6 项功能：直尺三模式（线段/射线/直线）、橡皮擦、水平垂直吸附、画面全屏、选线拖点、油漆桶填充。当前项目已模块化（config / geometry / store / view / snap / renderer / app），数据模型是"整段线段 + 整圆"，无法表达射线/直线/弧/附着点，需要先统一曲线模型，再逐项叠加功能。

## 模糊点的默认决策（可调整）

| 问题 | 默认决策 |
|---|---|
| 橡皮擦交互 | **拖动涂抹**擦除扫过的区间（圆的擦除方向由拖动方向决定，无歧义）；**单击**（位移<4px）删除整条曲线 |
| 全屏形式 | 画布铺满浏览器窗口（自适应窗口大小 + HiDPI），工具栏悬浮底部居中；另加一个调用原生全屏 API 的按钮 |
| 射线/直线的绘制范围 | 数学上无限，绘制时裁剪到当前视口 |
| 选线拖点的联动 | 拖动点时，以该点为端点/圆心的其他图形实时跟随变形（橡胶带式，GeoGebra 风格）——todo 第 6 条"填充跟随点滑动"隐含此需求 |
| 填充交互 | 点击封闭区域内部→提取该区域边界→存为参数化边界；点滑动时按边界参数实时重算多边形填充（不重提取拓扑） |

## 核心数据模型改造（P2，一切的基础）

统一曲线模型，替换现有 `circles[]` + `lines[]`：

```js
// 线型曲线：参数 t 为沿方向的有符号距离
{ id, type: 'line', kind: 'segment'|'ray'|'line'|'piece',   // piece = 擦除产生的碎片
  p0: {x,y}, dir: {x,y}, tMin, tMax }                        // segment:[0,L] ray:[0,∞) line:(-∞,∞)
// 圆型曲线：参数 t 为角度
{ id, type: 'circle', cx, cy, r, a0, a1 }                    // a1-a0 ≤ 2π，全圆 span=2π；擦剩的部分即弧

// 端点/圆心可携带附着约束（创建时若吸附到某曲线则记录）：
// attach: { curveId, t } —— 供选线拖点使用
curve.attach0 / attach1        // 线型两端
curve.centerAttach             // 圆心附着
```

`store.js` 改为 `curves[]` + `fills[]`，历史快照深拷贝两者；提供 `curvePointAt` / `curveParamOf` / `splitCurve(eraseRanges)` / `pickCurve(point, tol)`。

## 实施阶段（每阶段完成后浏览器验证）

**P1 全屏布局**
- `css/style.css`：body/app 铺满视口、去掉固定 900×650，画布 absolute 填充；工具栏毛玻璃悬浮底部居中，图例改为画布左上角半透明悬浮块
- `js/renderer.js`：`setSize(cssW, cssH, dpr)`（canvas.width = cssW×dpr，ctx 按 dpr 缩放），`js/app.js` 用 ResizeObserver 监听
- 工具栏加"全屏"按钮（requestFullscreen）
- `js/config.js`：删掉 CANVAS_WIDTH/HEIGHT，新增悬浮栏样式相关常量

**P2 曲线模型统一**（重构 store/geometry/snap/renderer，行为不变）
- `js/geometry.js` 新增：`curvePointAt`、`curveParamOf`（投影+域内判断）、`curveIntersection`（广义：参数域交集判定的线-线/线-圆）、`closestPointOnCurve`（弧外吸附到弧端点）、`clipLineToView`（射线/直线裁剪到视口矩形）、`sampleCurve`（弧多边形化，供填充）
- `js/snap.js` / `js/renderer.js` / `js/app.js` 全部迁移到曲线 API；交点标记、吸附、渲染、演示数据（2 全圆 + 2 线段）行为保持与现在一致

**P3 直尺三模式**
- `index.html` 工具栏加线段/射线/直线 分段按钮组（直尺激活时可用）
- `js/app.js`：`rulerKind` 状态；绘制射线/直线时起点固定、预览按方向裁剪；`finishDrawing` 生成对应 kind 的曲线
- 渲染/交点/吸附走 P2 的广义实现，自动支持

**P4 水平垂直吸附（0.5°，可开关）**
- `js/snap.js`：绘制中（phase='started'）新增候选类型 `'axis'`：startPoint→target 方向与 0°/90°/180°/270° 夹角 ≤0.5° 时，投影到该轴线上；优先级介于交点与端点之间
- 工具栏加"横平竖直"复选框（默认开）；吸附指示器显示"水平吸附/垂直吸附"

**P5 橡皮擦**
- 新工具按钮"🧹 橡皮"
- `js/store.js`：拖动中收集每条曲线被扫过的参数区间（鼠标移动段采样投影），mouseup 时 `splitCurve` 应用：线型切最多 2 段（射线/直线可能切成 段+射线/两条射线），圆切出弧，碎屑(<屏幕3px)丢弃，全擦除即删除；单击整条删除
- 删除/切碎时级联清理：引用被删曲线的 attach 与 fills
- 悬浮预览：橡皮光圈显示将要擦除的区间高亮

**P6 选择 + 沿线拖点**
- 新工具按钮"⬚ 选择"：点击选中曲线（高亮 + 描边加粗）
- 手柄 = 与选中曲线相关的附着点（引用它的端点/圆心 + 它自己已附着的端点/圆心）
- 拖手柄：`curveParamOf` 得到新 t → 更新拥有者曲线的端点坐标/圆心（刚性更新其它端），实时重渲染
- 创建图形时：起点/终点/圆心若被吸附（圆周/线上/端点/圆心/交点），写入对应 attach

**P7 油漆桶填充**
- 新工具按钮"🪣 填充" + 色板（8 预设色 + `<input type=color>` 自定义）
- 点击时一次性面提取（矢量法）：所有曲线求交→按参数切边→半边图→从离种子最近的边出发按同一侧绕行→得到封闭边界，存 `fill = { id, color, boundary: [{curveId, tFrom, tTo, reverse}] }`；失败提示"未找到封闭区域"
- 渲染：每帧按 `curvePointAt` 重算边界多边形（弧自适应采样）填充 → 点拖动时填充实时跟随；boundary 引用的曲线被删除时丢弃该 fill
- 填充绘制在最底层（网格之上、曲线之下）
